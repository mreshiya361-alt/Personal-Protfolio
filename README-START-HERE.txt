MAYANK RESHIYA PORTFOLIO — UPDATED VERSION

HOW TO RUN
1. Extract this ZIP file.
2. Open the "mayank-portfolio" folder in VS Code.
3. Open index.html in your browser, or use the VS Code Live Server extension.
4. The homepage hero now uses a custom red-and-black web-development workspace image in images/hero-developer-workspace.jpg.

IMPORTANT PERSONALIZATION (DO THIS BEFORE PUBLISHING)
Open js/main.js and update the CONFIG object:
- email: your real email address
- github: your GitHub profile URL
- linkedin: your LinkedIn profile URL
- whatsapp: optional phone number (not currently needed for the mailto form)

Also update:
- about.html: exact course, semester and education details
- resume.txt: accurate education, skills, projects and contact details
- projects.html: replace sample concepts with your real projects, screenshots, GitHub URLs and live demos
- index.html: update the social links and featured project details if needed

CONTACT FORM
The form validates entries and opens the visitor's default email application using mailto.
It does NOT send or store messages on a server. For a fully online form, connect a backend or a form service.
